# karthik-the-legend.github.io

The root of the GitHub Pages site. It holds `app-ads.txt`, which tells ad networks that the ads in
FormKit (`app.formkit`) are sold by this AdMob account, plus a small home page.

FormKit itself, with its privacy policy, lives in [play_store_app1](https://github.com/karthik-the-legend/play_store_app1).
